# Serious React Platform Foundation

Engineering-focused React/Next.js foundation: authentication, entitlements, Dashboard Studio, and a preview pipeline. A separate **Python/Discord** service handles bot traffic; the web app and bot integrate over HTTP with shared server-side auth patterns.
